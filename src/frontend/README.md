# shibhi.studio Frontend

A creative portfolio site built with React, TypeScript, and Tailwind CSS, deployed on the Internet Computer.

## Architecture

- **Frontend**: React + TypeScript with Vite build system
- **Backend**: Motoko canister on Internet Computer
- **Styling**: Tailwind CSS with OKLCH color system
- **State Management**: React Query for server state
- **Authentication**: Internet Identity

## Development

### Prerequisites

- Node.js 18+ and pnpm
- dfx (Internet Computer SDK)
- Internet Computer local replica running
