# Redeploy Runbook

This document describes the exact steps to perform a clean redeploy of the shibhi.studio application from a fresh checkout.

## Prerequisites

Before running the redeploy scripts, ensure you have:

1. **Node.js 18+** and **pnpm** installed
2. **dfx** (Internet Computer SDK) installed and configured
3. **Internet Computer local replica** running (for local deploys) or **mainnet wallet** configured (for production)
4. **Git repository** cloned to your local machine
